# Game music

Put songs in this folder and they play in the game for everyone, shuffled.
No code changes needed: every audio file here is picked up automatically.

- Formats: `.mp3`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.wav`, `.webm`
- The file name becomes the song title, e.g. `our-song.mp3` shows as "our song".
- Keep files reasonably small (a few MB each) so the game loads quickly on phones.
- GitHub rejects files over 100 MB.

**Only add music you have the right to share.** Files in this folder are published
on the public website. Songs you own, made yourself, or that are licensed for reuse
(e.g. royalty-free or Creative Commons) are fine.

To listen to any other song privately, use **Settings → Music → Add songs from device**
in the game instead: those stay on your own device and are never uploaded.
